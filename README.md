# 摸了么 · 法律与隐私

《摸了么》iOS 应用的公开隐私政策和用户协议页面，通过 GitHub Pages 发布。

## 在线地址

- 法律中心：https://zhenghaofeios.github.io/privacy/
- 隐私政策：https://zhenghaofeios.github.io/privacy/privacy-policy.html
- 用户协议：https://zhenghaofeios.github.io/privacy/terms-of-use.html

## 内容来源

当前版本与《摸了么》应用内 `lib/data/legal_docs.dart` 保持一致。
App 内法律文档更新后，可运行：

```sh
dart run tool/export_legal_site.dart <本站点目录>
```

重新生成并提交本仓库。
